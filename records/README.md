# EventHub – Event Booking Application

## 1. Project Overview

EventHub is an event booking platform developed
using Angular, ASP.NET Core Web API, and MySQL.

## 2. Project Goals

- User registration and login
- Browse and search events
- Book event tickets
- Organizer event management
- Admin event approval

## 3. Technology Stack

Frontend: Angular
Backend: ASP.NET Core Web API
Database: MySQL
ORM: Entity Framework Core
Authentication: JWT
Version Control: Git and GitHub

## 4. User Roles

- Customer
- Organizer
- Admin

## 5. Main Features

### Customer
- Registration and login
- Browse events
- Search events
- Book tickets
- View booking history

### Organizer
- Create events
- Update events
- Delete events
- Manage ticket availability
- View bookings

### Admin
- Manage users
- Approve events
- Manage organizers

## 6. Future Enhancements

- Online payments
- QR code tickets
- Email notifications
- Analytics dashboard
